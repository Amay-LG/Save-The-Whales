# data/
All coordinates are approximate placeholders. **Verify them against NOAA charts before the pitch.**

| File | Purpose |
|---|---|
| `land.geojson` | Simplified mainland coast and the Channel Islands (San Miguel, Santa Rosa, Santa Cruz, Anacapa), 10–30 vertices each. Used for land checks |
| `lanes.json` | Traffic separation scheme (TSS) lane centrelines per direction, with entry and exit gates |
| `vsr_zone.geojson` | Polygon of the vessel speed reduction (VSR) zone, used by the Blanket-VSR baseline |
| `whale_density.json` | MVP: Gaussian hotspot parameters. Stretch: a density grid built from sightings |
| `raw/` | (Stretch) pre-filtered AIS and sightings data. Git-ignored |
